# 隐私与数据处理

账本与设置保存在本机应用私有目录。基础记账、预算、统计和本地中文 OCR 不要求配置云端。

通知读取只在用户授权并选择来源后工作；无障碍用于支持付款页面的文字与窗口截图识别，不以残障辅助工具名义申请权限。关闭权限后不绕过系统继续读取。

默认不启用 DeepSeek。用户配置自己的 API Key 并同意后，本地识别失败的合适付款图片可能发送至 DeepSeek 服务。图片可能包含金额、商户和交易信息；使用前请阅读供应商条款。密钥使用 Android Keystore 保护的本地加密存储，不随公开 APK 或源码提供。

Google ML Kit 在设备上处理 OCR 输入；其 SDK 自身诊断与使用数据规则以 https://developers.google.com/ml-kit/terms 为准，因此“不上传图片用于本地 OCR”不等于所有第三方 SDK 绝不联网。

完整备份可能包含敏感账务及关联，请妥善保管。CSV 只导出流水，不能替代完整备份。卸载可能删除本机数据，请先备份。关闭截图提示只影响提示，不等于停止付款识别。

提交 GitHub Issue 时请勿附原始账本、付款二维码、完整订单号、API Key 或未脱敏截图；先遮盖私人信息。
