# 余白 · Android 自动记账与生活预算

面向学生生活的本地账本与预算应用。支持月计划、每日参考额度、手动记账、退款、活动预留、统计预测、备份恢复，以及实验性的微信 / 支付宝付款识别。HuanG已加入

**当前公开版本：0.2.31 / v0.2.31-beta.1，测试版，不是稳定正式版。**

[下载测试 APK](https://github.com/flandolusukalate/yubai-ledger/releases/tag/v0.2.31-beta.1) · [构建与运行](docs/BUILD.md) · [验证范围与已知问题](docs/VALIDATION.md) · [隐私说明](docs/PRIVACY.md) · [参与协作](CONTRIBUTING.md)

## 功能

- 月计划与实际到账分开；“生活费已到账”与收入关联，避免重复记收入。
- 所有页面共用账务规则，金额使用整数分；分类与承担预算分别保存。
- 明确付款经过查重后记录金额并预扣今日额度，用途后补、编辑和撤销后统一重算。预扣与正式流水不会同时扣两次。
- 自己账户间转账不算消费；退款与原消费关联；预算调整不改变真实资金。
- 默认本地中文 OCR；用户配置并同意后，仅本地识别失败才使用 DeepSeek 兜底。API 费用由用户自己的账户承担。
- 自定义截图规则：选择图片、标记金额/状态/商户、预览识别、实际窗口测试后启用。
- Overture 印纸主题与 Lens 印纸适配，共享账本，保留显影与弹簧动效。

## 自动记账如何工作

用户选定来源并授权 → 监听支持的付款页面或通知 → 一次高清本地 OCR → 失败时可选 DeepSeek → 判断金额、方向、付款状态 → 统一查重 → 自动付款占款 → 更新今日额度和月底预测。

截图提示仅表示图像已取得，不代表入账成功。截取后切回桌面可继续处理；服务被停止、授权被关闭或进程被终止时，未完成任务不保证继续。

没有交易号的成功页可能与另一笔同金额付款混淆，疑似重复会保留核对，不承诺所有同金额新付款都立即自动扣款。账单详情的完整交易号可帮助区分。

## 使用前须知

- Android 8.0 / API 26 起支持基础功能；无障碍窗口截图的可用性取决于系统版本、机型和页面，Android 8/9 不能据此宣称支持窗口 OCR。其他版本也需实测。
- **公开 APK 为 debug 构建和调试签名**，用于试用，不代表已完成正式签名与上架准备。未来更换签名可能无法直接覆盖安装，请先导出完整备份；不要为升级直接卸载有账本的版本。
- 无障碍、通知读取、截图提示和云端识别均为独立可选能力，拒绝后仍可手动记账。
- 一加“从最近任务划掉余白后无障碍断开”的用户报告尚未定位；长期后台、重启和省电策略待验证。
- 不保证微信、支付宝所有页面、小程序、分身或 NFC 场景自动识别。付款前后应核对账本；不要为测试额外消费。

首次启动为空账本。验收方案只有用户主动选择才填写计划，不预置私人账单、API Key 或付款截图。

## 快速开发

```sh
npm ci
npm test
npm run preview
# 配置 JDK 17/21、Android SDK 36 后：
./gradlew :app:assembleDebug :app:lintDebug
```

Windows 使用 `gradlew.bat`；预览地址为 http://127.0.0.1:4317，浏览器数据独立于手机。详细环境及原生测试见 [构建说明](docs/BUILD.md)。
